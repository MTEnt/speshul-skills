# Changelog

All notable changes to this project are documented here.

## 0.1.0 - 2026-08-07

### Added

- Local stdio MCP server with six narrowly scoped Facebook Page tools.
- Runtime-only token handling through an authorization header.
- Deny-by-default Page allowlisting.
- Expiring, content-hashed, single-use preview and approval workflow.
- Text, link, public HTTPS photo, and scheduled text/link publishing.
- Read-back verification that distinguishes publication success from verification failure.
- Unit and in-memory MCP integration tests with no live Facebook dependency.
