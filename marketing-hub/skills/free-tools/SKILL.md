# Free Tools

Build a real utility with explainable output. Do not disguise an opaque prompt or arbitrary score as analysis.

If `.agents/marketing-context.md` exists, read it first. Read [tool-workflow.md](references/tool-workflow.md) for tool types, ideation, MVP, gating, SEO, build choices, and evaluation.

## Operating contract

1. Define audience, triggering task, useful output, inputs, sensitivity, product relationship, and distribution path.
2. Confirm that computation or interaction creates more value than a static resource.
3. Specify logic, data, states, privacy, accessibility, analytics, limits, maintenance, and stale behavior.
4. Build or brief the smallest version that produces a trustworthy result.
5. Test normal, missing, invalid, extreme, repeated, mobile, and failure cases.

Do not collect data without need, imply diagnostic certainty, or build a maintenance burden with no owner.
