# Popup workflow

## Trigger choice

Use page or product state, referral source, known eligibility, meaningful scroll or content completion, repeated visit, basket or form state, inactivity, or genuine exit signal where technically reliable. Avoid arbitrary delay when it ignores user intent.

## Formats

- banner or sticky bar for broad low-friction announcements;
- inline or slide-in for contextual support;
- modal for a focused optional decision;
- full-screen interruption only for essential age, consent, security, or high-importance state;
- exit intervention for a distinct useful alternative, not repeated pressure.

## Message and form

State the value, relevance, commitment, privacy, and next state. Keep one primary action. For capture forms, apply the same label, validation, error, consent, and recovery standards as other forms.

Useful structures include problem and resource, current task and assistance, announcement and consequence, incomplete action and recovery, or explicit choice between paths. Do not use fake countdowns or vague rewards.

## Frequency and suppression

Define eligible pages, audience, minimum delay or behavior, maximum impressions, session and cross-session frequency, dismissal duration, conversion suppression, authenticated-user treatment, campaign end, and storage failure behavior. Fail toward less interruption when state is unknown.

## Accessibility and mobile

Move focus intentionally, trap it only while modal, announce the title, preserve keyboard escape and visible close, restore focus, prevent background interaction, respect zoom and viewport changes, avoid unexpected motion, and maintain readable content without horizontal overflow.

## Measurement

Track eligible exposure, view, dismiss, form start, validation error, conversion, downstream quality, page conversion, bounce, accessibility defects, complaints, and unsubscribe. Use a control or holdout when estimating incrementality.

## Output

Return purpose, audience, format, trigger and rule table, full copy and states, accessibility behavior, event plan, experiment variants, guardrails, and implementation QA.
