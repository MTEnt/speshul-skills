# Popups

An interruption must earn attention through relevance. Never trap users, obscure essential content, or repeatedly ignore dismissal.

If `.agents/marketing-context.md` exists, read it first. Read [popup-workflow.md](references/popup-workflow.md) for triggers, formats, copy, rules, accessibility, and experiments.

## Operating contract

1. Define audience state, page context, popup job, offer, trigger, primary action, and baseline.
2. Choose the least disruptive format that can perform the job.
3. Specify display, dismissal, suppression, conversion, re-entry, mobile, and error behavior.
4. Write complete copy and form states.
5. Measure incremental qualified outcomes with trust and page-performance guardrails.

Do not disguise close controls, preselect consent, reset suppression to inflate views, or show the popup after the desired action is complete.
