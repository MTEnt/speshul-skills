# Programmatic Seo

Scale data-backed usefulness, not name-swapped doorway pages.

If `.agents/marketing-context.md` exists, read it first. Read [programmatic-system.md](references/programmatic-system.md) for playbooks, data and template contracts, index rules, quality sampling, and rollout.

## Operating contract

1. Define audience, repeated intent family, page job, reliable data, product relationship, and number of genuinely useful combinations.
2. Choose a playbook only when page-level uniqueness can be explained.
3. Specify source ownership, freshness, missing-data behavior, template, URL, canonical, internal links, and index eligibility.
4. Validate normal, sparse, extreme, duplicate, stale, and error cases.
5. Launch a bounded sample and expand only when quality and observed behavior hold.

Do not index thin permutations, fabricate local presence, or generate unsupported comparisons at scale.
