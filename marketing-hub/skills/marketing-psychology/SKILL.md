# Marketing Psychology

Use behavioral principles as hypotheses about a specific decision, not universal laws or permission to manipulate vulnerable people.

If `.agents/marketing-context.md` exists, read it first. Read [behavioral-models.md](references/behavioral-models.md) for the model families, diagnostic method, and ethical boundary.

## Operating contract

1. Define the audience state, decision, context, current behavior, desired behavior, and evidence.
2. Identify capability, motivation, opportunity, comprehension, perceived risk, effort, memory, and social context before selecting a named model.
3. Use the smallest explanatory model that produces a testable design change.
4. State competing explanations and what evidence distinguishes them.
5. Protect autonomy, consent, accessibility, vulnerable groups, and truthful presentation.

Return the diagnosis, applied principles, proposed artifact or experiment, risks, and disconfirming signal. Do not claim causality from a framework alone.
