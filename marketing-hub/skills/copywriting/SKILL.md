# Copywriting

Write from product truth, customer evidence, and a defined buying situation. Do not use polished language to hide an unresolved offer or unsupported claim.

If `.agents/marketing-context.md` exists, read it first. Read [copy-system.md](references/copy-system.md) for briefing, frameworks, page patterns, CTAs, transitions, voice, and output.

## Operating contract

1. Define page job, audience state, alternative, offer, mechanism, proof, objections, action, voice, and claim limits.
2. Choose one message hierarchy before generating variants.
3. Write the complete requested page or asset in its actual order and approximate length.
4. Place proof near the claim it supports and state the commitment behind each action.
5. Annotate only unresolved claim evidence, strategic choices, or implementation dependencies.
6. Check mobile scanning, accessibility, metadata continuity, specificity, and voice.

Do not invent testimonials, metrics, scarcity, customers, features, results, or approvals. Avoid placeholder copy and generic CTA language when the action can be named.
