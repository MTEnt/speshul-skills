# Sales Enablement

Build the asset required for the sales moment. A generic deck is not the default answer to every enablement problem.

If `.agents/marketing-context.md` exists, read it first. Read [enablement-system.md](references/enablement-system.md) for asset frameworks, proof, governance, usage, and output.

## Operating contract

1. Define audience role, buying stage, decision or risk, seller behavior, alternatives, proof, delivery format, owner, and update trigger.
2. Inspect current product, price, implementation, security, legal, customer proof, and competitive evidence.
3. Choose and complete the narrowest useful asset.
4. State claims, proof, source dates, better-fit competitor cases, and seller concessions.
5. Include usage guidance, editable source, owner, review date, and expiry condition.

Do not invent customer quotations, ROI, security posture, product behavior, competitor failures, or deal outcomes.
