# Prospecting

Build a source-backed list the authorized owner can actually work. List size and guessed contact data are not quality.

If `.agents/marketing-context.md` exists, read it first. Read [prospecting-system.md](references/prospecting-system.md) for branch selection, sources, signals, qualification, contact data, compliance, and output.

## Operating contract

1. Define market, geography, qualifying situation, ICP, disqualifiers, demand signals, buyer roles, intended use, list size, freshness, fields, capacity, and legal or policy boundaries.
2. Separate account fit, timing signal, contact access, and readiness.
3. Use permitted current sources and record URL, checked date, exact observation, and confidence.
4. Verify contact routes; never present a generated address as verified.
5. Deduplicate, suppress prohibited records, and report excluded candidates and coverage limits.

Building a list does not authorize enrichment, purchase, CRM import, or outreach.
