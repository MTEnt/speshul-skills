# Directory Submissions

Submit accurate product information where the directory has a real audience or trust role. Mass submission to low-quality sites is not a strategy.

If `.agents/marketing-context.md` exists, read it first. Read [directory-workflow.md](references/directory-workflow.md) for selection, positioning variants, Product Hunt, reviews, destination pages, tracking, and maintenance.

## Operating contract

1. Define product, category, geography, launch state, audience, approved claims, assets, budget, and owner.
2. Verify current directory audience, submission rules, cost, editorial model, ownership, data use, and update access.
3. Prioritize quality and relevance; do not treat a dofollow attribute or domain metric as sufficient value.
4. Prepare consistent core facts with audience-specific descriptions and categories.
5. Require explicit authorization before submitting, paying, claiming profiles, or requesting reviews.

Do not create fake reviews, undisclosed editorial claims, false launch activity, duplicate identities, or irrelevant bulk listings.
