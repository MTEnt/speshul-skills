# Onboarding

Design the minimum path to experienced value. Product tours are not a substitute for a coherent workflow.

If `.agents/marketing-context.md` exists, read it first. Read [activation-workflow.md](references/activation-workflow.md) for activation models, components, branching, recovery, and experiments.

## Operating contract

1. Define the customer's intended progress and observable activation behavior.
2. Inspect prerequisites, setup, first action, first result, repeat value, team value, and failure paths.
3. Remove or defer work that does not contribute to value, security, or required configuration.
4. Specify complete steps, states, copy, events, assistance, persistence, and channel handoffs.
5. Measure downstream retention and quality, not checklist completion alone.

Return the activation definition, journey map, revised flow, event contract, dependencies, and decision rule.
