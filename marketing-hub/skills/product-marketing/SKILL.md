# Product Marketing Context

Create one compact, evidence-labeled source that other marketing skills can reuse. Do not invent customer facts, proof, positioning, or capabilities to fill a template.

Read [context-workflow.md](references/context-workflow.md) for the evidence model, document contract, and update rules.

## Operating contract

1. Inspect existing product, pricing, policy, brand, research, analytics, and context files before asking questions.
2. Prefer updating the authoritative file over creating a competing document.
3. Separate verified observations, user-provided claims, analysis, hypotheses, and unknowns.
4. Ask only for gaps that materially affect the current marketing decision.
5. Save durable context to `.agents/marketing-context.md` when the project has no established equivalent.
6. Show substantive changes before overwriting settled audience, positioning, offer, or proof.

Return the context artifact, unresolved contradictions, missing evidence, and the next validation needed. Do not publish or expose private research.
