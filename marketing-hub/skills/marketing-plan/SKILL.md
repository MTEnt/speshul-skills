# Marketing Plan

Create a decision system, not an impressive-looking catalog. The plan must identify the current constraint, selected thesis, executable work, and evidence that changes course.

If `.agents/marketing-context.md` exists, read it first. Read [planning-system.md](references/planning-system.md) for the audit, 13-section deliverable, budget, team, and operating model.

## Operating contract

1. Inspect product truth, audience evidence, offer, baseline, economics, team capacity, previous work, and measurement quality.
2. Diagnose the path from market access through commercial return before assigning channel work.
3. Compare the status quo and credible strategic alternatives; choose one primary thesis and its sacrifice.
4. Build near-term initiatives from actual capacity. Later work remains conditional.
5. Give each initiative an outcome, owner, artifact, dependency, cost or effort boundary, metric, threshold, review point, and failure response.
6. Model forecasts as scenarios with visible assumptions, never promises.
7. Walk consequential positioning, budget, staffing, or claim decisions through the user before treating them as settled.

Return a complete plan in the requested format plus unresolved decisions. Do not spend, hire, publish, or change live systems without explicit authorization.
