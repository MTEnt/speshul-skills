# Design provenance

This hub is an original package. Its taxonomy is organized by the decision each skill answers, in eight stages: Evidence, Decision, Make, Convert, Reach, Discover, Measure, Operate. Every skill shares the truth file, the evidence states, the claim ledger, and the deliverable contracts defined in the orchestrator's references.

Version 1 checked its coverage against publicly available marketing skill libraries. No text, code, or file from any external library was vendored, and version 2 replaced the version 1 skill list with the stage-based design above. Frameworks referenced in the references are cited to their public sources where a specific idea is used.

This note documents design origin; it is not a legal clean-room attestation.
