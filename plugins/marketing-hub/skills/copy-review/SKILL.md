# Copy Review

Edit the cause of the weakness, not merely sentence rhythm. Preserve the author's meaning unless the requested decision requires a strategic change.

If `.agents/marketing-context.md` exists, read it first; it is the truth file every skill in this hub shares, and its evidence states are constraints. Read [editing-system.md](references/editing-system.md) for the seven passes, scoring, common corrections, refresh work, and output modes.

## Operating contract

1. Establish the asset's job, audience, offer, intended action, voice, and the scope of permitted change.
2. Inspect current product, price, availability, proof, and dates before editing factual claims.
3. Separate strategy problems from structure, language, and correctness problems, and edit in a stable sequence so later polishing does not preserve a false or misplaced message.
4. Return clean copy, a redline or change log when requested, and unresolved strategic or factual issues, stating whether each change is factual, strategic, structural, voice, or mechanical.

Do not invent proof, silently change commercial meaning, flatten intentional voice into generic simplicity, or change publication dates to make old content look new.

## Return

The edited copy in the requested mode plus the claim-verification table and open issues.
