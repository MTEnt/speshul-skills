# Ad-format blueprints

Confirm placement specifications from current official sources before export. These blueprints define information and production logic, not fixed pixel or character limits.

## Static concept

Return concept ID, communication job, audience cue, lead line, support line, product or evidence layer, brand layer, action, composition, crop behavior, source assets, rights, claim source, accessibility text, and export set.

Useful structures include a clear proposition, product mechanism, evidence callout, problem and resolution, valid comparison, objection answer, founder or operator note, review with permission, educational diagram, or offer terms. Choose one dominant hierarchy.

## Carousel or document

Specify a cover promise, ordered frame jobs, one main decision per frame, continuity device, proof placement, product reveal where useful, final action, caption, alt text, and per-frame source or rights. The frames must form an argument or demonstration rather than a pile of independent cards.

## Responsive search assets

Return destination and intent, campaign context, prohibited claims, distinct headline and description assets, current character validation, optional pinning with reason, paths or equivalent display fields, supporting extensions or assets, and a duplicate-intent check. Assets must combine coherently in plausible permutations.

## Vertical short-form video

Define opening-frame recognition, premise without sound, beat-by-beat visuals, spoken line, on-screen text, demonstration, proof, action, duration budget, safe zones, caption treatment, music or sound rights, disclosure, source assets, edit notes, and exports.

Possible production modes include creator explanation, product demonstration, screen recording, interview or documentary material with consent, motion typography, generated scene with disclosure where required, comparison, or a platform-native visual device that does not impersonate a private message.

## Motion or generative sequence

Record the factual subject, desired action, visual system, shot or scene plan, camera behavior, motion purpose, continuity constraints, negative constraints, reference rights, tool and version, generation identifiers, edits, audio source, disclosure state, and a fallback if generated material is unusable.

## Batch package

Use stable IDs and a bounded matrix:

```text
concept x audience situation x format x proof dimension
```

Only one dimension should change when interpretation matters. Return a manifest with filename, source, version, placement, copy, destination, rights, approval, test cell, and control relationship. Reject duplicates, unsupported claims, broken destinations, and incomplete fields before review.

## Iteration readout

Separate delivery failure, attention failure, qualified-response failure, destination failure, sales-quality failure, and fatigue. Preserve useful elements only when downstream evidence supports them. Return winners, losers, ambiguous cells, causal limits, new hypotheses, assets to keep or retire, and the smallest next matrix.
