# Truth File

Produce one compact, evidence-labeled source that every other skill in this hub reads first. Do not fill a template with invented customers, proof, positioning, or capabilities.

Read [context-workflow.md](references/context-workflow.md) for the evidence states, section contract, and update rules.

## Operating contract

1. Inspect existing product, pricing, policy, brand, research, analytics, and context files before asking questions.
2. Prefer updating the authoritative file over creating a competing document.
3. Separate verified observations, user-provided claims, analysis, hypotheses, and unknowns, with sources and checked dates where facts drift.
4. Ask only for gaps that materially affect the current marketing decision.
5. Save durable context to `.agents/marketing-context.md` when the project has no established equivalent; show substantive changes before overwriting settled audience, positioning, offer, or proof.

Do not publish or expose private research, merge a buying group into one fictional persona, or record decorative demographics that change no decision.

## Return

The truth file or its diff, unresolved contradictions, missing evidence, and the next validation needed.
