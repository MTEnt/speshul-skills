# Organic Social

Build channel-native assets from a useful thesis and verified evidence. Posting volume and engagement are not automatically business value.

If `.agents/marketing-context.md` exists, read it first; it is the truth file every skill in this hub shares, and its evidence states are constraints. Read [social-system.md](references/social-system.md) for channel jobs, platform fit, themes, hooks, listening, repurposing, and measurement. Read [asset-blueprints.md](references/asset-blueprints.md) when producing complete posts, threads, carousels, scripts, or listening briefs.

## Operating contract

1. Define audience, relationship state, channel job, desired behavior, evidence, offer, voice, and production capacity.
2. Verify current platform formats, limits, link behavior, scheduling, disclosures, and API rules from official sources.
3. Choose a repeatable content thesis and a few supported themes.
4. Produce complete platform-ready assets with media notes, sources, alt text or captions, disclosure, and CTA where appropriate.
5. Require approval before posting, scheduling, replying, or representing the user publicly.

Do not use engagement bait, fake controversy, copied hooks, fabricated experience, mass replies, hidden automation, or scraping around access controls.

## Return

Channel thesis, themes, finished assets, media and disclosure notes, engagement or listening plan, calendar when requested, measurement, and learning cadence.
