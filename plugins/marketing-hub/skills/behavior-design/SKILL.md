# Behavior Design

Behavioral principles are hypotheses about a specific decision, not universal laws or permission to manipulate vulnerable people.

If `.agents/marketing-context.md` exists, read it first; it is the truth file every skill in this hub shares, and its evidence states are constraints. Read [behavioral-models.md](references/behavioral-models.md) for the model families, diagnostic method, and ethical boundary.

## Operating contract

1. Define the audience state, decision, context, current behavior, desired behavior, and evidence.
2. Identify capability, motivation, opportunity, comprehension, perceived risk, effort, memory, and social context before selecting a named model.
3. Use the smallest explanatory model that produces a testable design change; state competing explanations and what evidence distinguishes them.
4. Protect autonomy, consent, accessibility, vulnerable groups, and truthful presentation.

Do not claim causality from a framework alone or use defaults, framing, or social proof that misleads.

## Return

The diagnosis, applied principles, proposed artifact or experiment, risks, and disconfirming signal.
