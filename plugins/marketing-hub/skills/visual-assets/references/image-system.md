# Image system

## Choose the method

- product capture when real interface, workflow, or output is the evidence;
- photography when a real person, place, object, or process matters;
- designed composition for typography, diagrams, comparisons, or brand systems;
- illustration for abstraction, instruction, or a constructed visual world;
- generative image for bounded non-documentary concept or controlled variation;
- stock for speed and realism with valid license;
- hybrid when sourced or generated material supports truthful product and type layers.

## Generative prompt contract

Specify subject, action, environment, composition, camera or perspective, lighting, material, palette, art direction, aspect, crop flexibility, negative constraints, exact elements that must remain truthful, and reference-image rights.

Generate a small exploratory set, select against the communication job, then refine one direction. Track tool or model, date, prompt, references, seed or identifier when available, edits, and rights state. Do not request a living artist's style identity.

## Product screenshots and mockups

Use real product state or label conceptual UI. Prepare clean data, remove private data, secrets, unrelated accounts, notifications, and unstable timestamps. Preserve legibility at final size. Avoid perspective or device effects that obscure evidence.

## Designed graphics

Define grid, type, hierarchy, brand assets, data source, contrast, icon and illustration language, responsive variants, and editable source. Validate spelling, numbers, logo clearance, and visual distinction from references.

## Optimization

Choose SVG for suitable vector work; AVIF or WebP for efficient photographic delivery with needed fallback; PNG for transparency or lossless UI where justified; JPEG for compatible photographic compression. Provide intrinsic dimensions, responsive sources, lazy loading outside critical content, stable layout, color profile, compression, and descriptive filenames.

Common local tools may include ImageMagick, `cwebp`, `avifenc`, or platform build tooling. Verify installed versions and compare output visually before replacing sources. Preserve originals and metadata only when needed.

## Accessibility

Write alt text for information conveyed by the image; use empty alternative text for decoration. Do not repeat nearby copy unnecessarily. For charts or complex diagrams, provide an equivalent textual explanation or data table.

## OG and social previews

Verify metadata, absolute URL, current platform crop behavior, final text size, brand recognition, caching, and deployed preview. Provide a safe composition that survives common crops.

## Quality gate

Check five-second comprehension, hierarchy, brand distinction, product truth, spelling, contrast, crop, safe zones, accessibility, file size, rights, disclosure, metadata, export naming, and reproduction notes.

## Output

Return final asset or production-ready brief, editable source or recreation record, export variants, alt text, rights and disclosure, optimization evidence, and QA.
